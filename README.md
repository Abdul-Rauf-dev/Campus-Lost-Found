# Campus Lost & Found — Web Technologies SP26

A simple Lost & Found platform built with vanilla JavaScript + JSON Server.

## Setup (one time)

1. Install Node.js if you have not already: https://nodejs.org
2. Open a terminal in this folder.
3. Install JSON Server globally:

       npm install -g json-server

## Running the app

1. In the project folder, start the server:

       json-server --watch db.json

   This starts a fake REST API at http://localhost:3000

2. In a separate window, open `index.html` in your browser
   (or use Live Server in VS Code for auto-reload).

3. To access the admin panel, navigate to `admin.html`.

## API Endpoints (auto-generated by JSON Server)

- GET    /reports               → all reports
- GET    /reports/1             → report with id = 1
- GET    /reports?type=lost     → only lost reports
- GET    /reports?category=keys → filter by category
- POST   /reports               → create a new report
- PUT    /reports/1             → replace report 1
- DELETE /reports/1             → delete report 1

## Files

- `index.html`  — User panel (browse + post)
- `admin.html`  — Admin panel (review + manage)
- `style.css`   — Shared styles (sage & coral palette)
- `app.js`      — User panel JavaScript
- `admin.js`    — Admin panel JavaScript
- `db.json`     — Database file (auto-updated by JSON Server)
